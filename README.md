# SC-Internal-Tools 👋

### ⚙️ Operational Tools & Workflow Automation

Official repository organization for Software Control (SC) internal utility tools and process automation at Octagon Express Group.

---

### 🛠️ Tech Stack

- **Runtime & Scripts:** Node.js, TypeScript, Python, REST APIs
- **Integrations:** SharePoint API, Telegram Bot API, Jenkins, Custom Email Dispatchers

---

### 📌 Focus Areas

- **Data Extraction:** Automated SharePoint Excel file downloaders and parsers.
- **Reporting Infrastructure:** Automated daily and weekly test report generators.
- **Process Optimization:** Utility scripts to streamline repetitive operational and QA tasks.
